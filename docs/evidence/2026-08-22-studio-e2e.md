## 발견
1. **초안(draft)은 API에서 안 보인다.** `No default config found` → 헤더 `설정 #1 초안 ▾ → 저장` 후 호출 가능. (= config 고정의 실체)
2. **`output[].model` 값**: `step_1_parse`, `step_2_classify`, **`Information Extract - Extract-1`** (step_N 형식이 아님). 파서는 `/parse|classify|extract|instruct|validate/i` 정규식 + `previous_step_name` 체인으로 찾는다. 배열 순번 금지.
3. `content[].additional_values`는 **객체**(문자열 아님)로 옴: `previous_step_name`, `step_run_id`, `cache_hit`, 그리고 Extract는 필드별 `{_value, confidence(high|low), page, coordinates[4], word_coordinates}`.
4. Classify `additional_values.document_type`에 `confidence_score`(0~1)와 `confidence`(high|low) **둘 다** 있음. `hierarchy {leaf, path, depth}`도 옴 → L2 계층 쓰면 path로 받는다.
5. 미매핑 타입은 Extract 단계가 **응답에서 통째로 빠진다** (빈 결과가 아님). 파서는 "단계 없음"을 정상 경로로 처리해야 한다.
6. 광고 오분류: 기본 `others` 설명이 약함. → `ad` 타입을 명시적으로 추가. 이때 confidence가 `low`였으므로 R3 게이트가 사람 확인으로 돌렸을 것 — 데모 포인트.
7. Parse HTML에서 `·` → `■`로 깨짐. 표시용이 아니라 무시.
8. 처리시간 n=3: 8.9 / 9.3 / 13.5s. 대기 UX는 15초 기준으로 설계해도 됨.
