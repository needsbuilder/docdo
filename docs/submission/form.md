## Punchline (≤200)

어르신은 우편물을 찍어 듣고, 자녀는 공식 정보와 대조한 결과를 보고 승인하고, 에이전트가 처리합니다 — 인증은 사람이 합니다.

## Description (≤5000, markdown)

**독도(DocDo)** 는 문해력이 취약한 고령자의 우편물 문제를 "읽기"가 아니라 **"판단"** 의 문제로 봅니다. 무엇이 왔는지, 진짜인지, 무엇을 해야 하는지를 혼자 정하기 어렵기 때문에, 어르신에게는 **이해·안심·위험 경고**만 주고 **행동은 전부 자녀 화면으로** 옮깁니다.

### 흐름

1. **어르신이 우편물을 찍습니다.** 계정 없이, 자녀가 보낸 링크 한 번으로 연결됩니다(홈 화면 아이콘).
2. **Upstage Studio 에이전트**가 읽습니다 — Document Parse → Classify(pay / apply / info / ad) → Extract 분기 2개.
3. **검증 계층**이 추출값을 공식 기관 레지스트리와 대조합니다(R1 발신 정합성 · R3 신뢰도 게이트 · R4 개인 휴대전화 · R5 분류 신뢰도 · R6 예금주 정합성).
4. **두 화면** — 어르신 폰: 큰 글씨와 음성(ElevenLabs)으로 "문서에 적힌 내용"만. 자녀 폰: 판정 칩·핵심값·해야 할 일·대조 근거 카드.
5. 자녀가 **[납부 처리 승인]** 을 누르면 **Solar Pro 4 브라우저 에이전트**가 납부 포털에서 고지 내역을 조회하고, 화면 금액이 문서 금액과 같을 때만 진행합니다.
6. **본인인증 단계는 사람에게 넘깁니다.** 자녀가 폰에서 실시간 화면을 직접 눌러 마치고 [이어서 하기]를 누릅니다.
7. 완료되면 어르신 화면이 스스로 **"처리됐어요 · 납부확인번호"** 로 바뀝니다 — 닫힌 루프.

### Upstage 활용

- **Studio 에이전트가 문서 처리 파이프라인의 핵심**입니다. `include: ["all"]` 로 필드별 confidence·좌표를 받아, `low` 인 값은 음성으로도 화면으로도 읽지 않습니다. Classify 범주가 `low` 여도 점수가 0.9 이상이면 추출을 계속하고 대조로 판정합니다.
- **Solar Pro 4** 는 페이지의 접근성 트리(버튼·입력·링크 + 참조 번호)를 읽고 `click / type / press / scroll / wait_human / done / abort` 중 한 번에 하나만 결정하는 브라우저 에이전트의 두뇌입니다. 픽셀 computer-use 가 아니라 **구조를 읽고 행동**합니다.
- 실측한 플랫폼 함정도 기록했습니다(초안 config 는 API 에서 보이지 않음 · 미설정 노드가 있으면 저장 거부 · `["last"]` 면 confidence 소실 · 미매핑 타입은 Extract 단계가 응답에서 통째로 빠짐).

### 안전 원칙 (다른 모든 결정보다 우선)

1. 어르신 화면에 **금전 거래로 이어지는 경로가 없습니다** — 계좌번호·납부 버튼·결제 링크 없음.
2. **확신하지 못한 값은 읽지 않습니다.**
3. **지시하지 않고 사실만 전달합니다.** "내시면 됩니다" ✗ → "문서에 적힌 금액은 …" ✓
4. 폐기를 지시하지 않습니다.
5. 문서에서 추출한 연락처·링크는 **실행 경로가 되지 못합니다.** 전화는 레지스트리의 공식 번호로만.

에이전트 가드레일은 코드에 있습니다: 비밀번호·인증서는 절대 입력하지 않음 · 납부 버튼은 문서 금액이 화면에 보일 때만 · 허용 도메인 밖 차단 · 같은 화면 3회·25단계 초과 시 중단 · `done` 은 납부 클릭 후에만.

### 검증 — 합성 시나리오 회귀 결과

- **통제 실험**: 같은 고지서에서 문의전화·안내 주소 **두 필드만** 바꾼 변조본을 Extract 는 정확히 읽었고, 판정을 가른 것은 레지스트리 대조였습니다(통제본 `clear` 2/2, 변조본 `mismatch` 0/2). "AI 가 가짜를 알아본다"가 아니라 **공식 정보와 대조해 다른 점을 찾습니다.**
- 팀 합성 fixture 12장 **12/12** · 촬영 열화 시뮬레이션 mid **12/12** · hard **11/12** (열화 시 조용히 틀리지 않고 `low` → 사람에게 넘김) · 회귀 시험 **296개**.
- 처리시간은 관측 범위 **4.1~26.2초**(n=12)입니다. P95 가 아닙니다.

### 한계 — 먼저 밝힙니다

- `clear` 는 **"확인된 불일치 없음"** 이지 "정상·진짜·안전"이 아닙니다. 화면에도 무엇을 몇 개 확인했고 무엇을 안 했는지를 보여줍니다.
- **공식 연락처를 그대로 복사한 사칭 문서는 이 방식으로 탐지하지 못합니다.**
- 레지스트리는 **8개 기관 시범 적용**이며 민간 사업자는 대조 대상이 아닙니다. 계좌의 실제 명의는 조회하지 않습니다.
- 실제 인터넷지로는 비회원도 금융인증서가 필수라 인증 이후 단계가 미구현입니다. 같은 흐름의 **시연용 포털**에서 처리하며, [실제 인터넷지로에서]는 인증 벽에서 보호자에게 넘어오는 것까지 보여줍니다.
